2.4 DataAgent 前台
Data Agent 首页是业务用户进入智能数据分析助手后的首屏页面。页面用于展示当前可用 Agent、历史对话、推荐问题、经营洞察场景和自然语言提问入口，帮助用户快速发起数据分析、继续历史会话，或直接进入已配置好的经营洞察仪表盘。

对话与输出	
对话：

支持用户快速新建一轮 Data Agent 对话，新建对话默认在当前agent下新建，Agent 只能选择已经在后台配置过的智能体。
展示推荐问题和快捷场景，推荐问题默认展示6个，大于6个时有“换一换”按钮，3-6的问题可以没有换一换
点击洞察快捷场景提问，相当于对话形式交互，有思考过程，一个场景卡片，点卡片会预览整体输出结果，结果中指标卡最多8个，图表3-9个，可以有重复的类型 的图表
支持自由对话，但都依赖智能体绑定的数据表，无法回答时不能编造数据
支持意图识别自动切换agent，例如当前在BB-agent下，问与AA-agent相关的问题时，需要自动切换AA agent，可以通过推荐问题和绑定的数据来识别
