# 1 产品概述

Data Agent 是面向业务用户的智能数据分析助手，支持基于自然语言进行数据问答、图表生成和经营洞察分析。管理员先在后台完成数据准备、指标配置和 Agent 创建，业务用户即可在前台通过对话方式快速获取分析结果。

Data Agent 与智能建模助手的区别：

| 对比项 | Data Agent | 智能建模助手 |
|--------|------------|--------------|
| 主要目标 | 数据问答、指标分析、图表洞察 | 可视化建模、算子编排 |
| 核心对象 | 数据表、指标、洞察场景 | 数据表、算子、模型画布 |
| 典型输出 | 指标卡、图表、洞察仪表盘 | 建模方案、算子节点 |
| 主要用户 | 业务分析师、经营分析人员 | 模型开发者、数据分析师 |

本手册面向已具备平台访问权限的用户，说明如何从数据准备到前台问答完成 Data Agent 的配置与使用。

## 1.1 产品架构

Data Agent 由「后台配置层 + 前台交互层 + 智能分析层」组成：

| 层级 | 组成 | 作用 |
|------|------|------|
| 后台配置层 | 数据准备、指标库、Agent 管理、洞察场景、行业词库 | 配置 Agent 可访问的数据范围、指标口径和分析模板 |
| 前台交互层 | Agent 卡片、对话区、推荐问题、洞察场景、历史会话 | 接收用户提问并展示分析结果 |
| 智能分析层 | 意图识别、指标召回、图表生成、场景匹配、洞察总结 | 基于绑定数据和指标生成结构化分析结果 |

整体流程：

```
数据准备（接入表 + 元数据 + 维度和指标）
        ↓
指标库（原子/派生/复合指标统一管理）
        ↓
Agent 管理（选表、绑指标、推荐问题、洞察场景、词库）
        ↓
Data Agent 前台（自然语言问答 / 场景洞察 / 图表输出）
```

## 1.2 核心价值

1. **降低分析门槛**：用户用自然语言提问，无需编写 SQL 或手工配置图表。
2. **统一指标口径**：优先使用指标库中已发布、已绑定的指标，避免口径不一致。
3. **快速洞察经营情况**：通过预设洞察场景，一键生成指标卡、核心图表和深度分析。
4. **支持多 Agent 分工**：不同业务域可配置独立 Agent，分别绑定不同数据表和指标。
5. **增强业务理解能力**：通过行业词库提升术语识别和自然语言理解准确性。

## 1.3 用户角色

| 角色 | 主要权限 | 典型操作 |
|------|----------|----------|
| 业务分析师/普通用户 | 使用已启用 Agent 进行问答和洞察 | 切换 Agent、提问、查看图表、使用洞察场景 |
| 数据管理员 | 管理数据表、元数据、维度和指标 | 添加数据表、AI 生成元数据、维护指标库 |
| 系统管理员 | 管理 Agent、洞察场景、词库和启用状态 | 新建 Agent、配置范围、维护洞察模板 |

# 2 后台管理操作流程

## 2.1 数据准备

数据准备用于管理 Data Agent 可使用的数据资产，包括数据表、维度、指标等。平台用户可接入已治理的标准表，或通过 AI 自动补齐表元数据和字段元数据。

### 2.1.1 查看数据表列表

#### 操作流程

`数据准备 → 数据表列表 → 查看/搜索/分类管理`

#### 操作步骤

1. 进入【数据准备】模块。
2. 在左侧目录中查看数据表分类；系统默认包含【全部分类】和【未分类】。
3. 使用搜索框按表中文名检索目标数据表。
4. 在右侧列表查看表中文名、原始名、业务描述、主题域、分类、字段数、数据量和更新时间。
5. 点击某张表，进入表详情页。

#### 分类管理说明

- 点击分类右侧「+」可新建一级文件夹；在文件夹上点击「+」可新建子文件夹。
- 分类最多支持 5 层。
- 分类名称不允许重名。
- 【全部分类】【未分类】为系统默认分类，不可编辑和删除。

### 2.1.2 从万象添加数据表

#### 操作流程

`数据准备 → 添加数据表 → 选择表 → AI 生成元数据 → AI 生成维度/指标 → 完成`

#### 操作步骤

**第一步：选择表**

1. 点击【添加数据表】或【从万象添加表】。
2. 在左侧勾选需要接入的数据表，已选表会自动出现在右侧。
3. 支持搜索表中文名、分类名；支持一键清空已选表。
4. 至少选择 1 张表后才能进入下一步；单次最多选择 10 张表。
5. 已经添加过的表不可重复选择。

**第二步：AI 生成元数据**

1. 点击【开始批量生成】，为所有已选表生成元数据；或点击【生成当前表】仅为当前表生成。
2. AI 将基于表名、字段名、字段类型和样例数据，自动生成表和字段业务元数据。
3. 检查并补充以下必填项：
   - 表元数据：中文名、分类、业务描述
   - 字段元数据：业务含义等必填信息
4. 源字段名、源字段类型不支持修改。
5. 必填项为空时无法进入下一步。

**第三步：AI 生成维度/指标**

1. 查看 AI 推荐的原子指标、派生指标或复合指标及对应维度。
2. 根据需要新增、编辑或删除维度和指标。
3. 维度必须来自现有表字段；若选择了不存在的维度，系统会提示「该维度在表中不存在」。
4. 完成配置后点击【完成并加入编目】。

#### 操作说明

- 从万象添加表时，若未选择分类，默认加入【未分类】。
- 若数据表已绑定指标且相关 Agent 已启用，则该表不可删除。
- 支持多选批量删除数据表。

### 2.1.3 编辑表详情

进入表详情页后，可执行以下操作：

| 模块 | 操作 |
|------|------|
| 表元数据 | 编辑表名、分类、业务描述 |
| 字段元数据 | 编辑字段业务含义、枚举值；保存后生效，取消则恢复上次保存内容 |
| 数据预览 | 查看样例数据，支持导出 |
| 维度/指标 | 预览、新增、编辑、删除维度和指标 |

---

## 2.2 指标库管理

指标库用于统一管理 Data Agent 可复用的业务指标，包括原子指标、派生指标和复合指标。Agent 在问答和分析时应优先使用指标库中已发布、已绑定的指标口径。

### 操作流程

`指标库 → 选择目录/数据表 → 查看指标 → 创建/编辑/发布指标`

### 操作步骤

1. 进入【指标库】模块。
2. 左侧目录与【数据准备】中的分类保持一致。
3. 可按目录名称、表名搜索；点击某张表后，右侧仅展示该表下指标。
4. 通过 Tab 切换查看【原子指标】【派生指标】【复合指标】；Tab 名称后展示对应数量。
5. 点击【创建指标】，跳转至对应类型的指标创建页面。
6. 创建完成后，可在列表中预览、编辑和发布指标。

### 指标类型说明

| 类型 | 说明 |
|------|------|
| 原子指标 | 基于单表字段直接统计的基础指标 |
| 派生指标 | 基于原子指标和业务规则加工形成的指标 |
| 复合指标 | 基于多个指标和对齐维度计算形成的指标 |

### 操作说明

- 指标库来源表为数据准备中已接入并分类的数据表。
- Agent 问答时优先引用已绑定且已发布的指标，避免由大模型临时推断口径。
- 某类型下无指标时，页面展示空状态。

## 2.3 Agent 管理

Agent 管理用于创建和维护 Data Agent 实例，配置每个 Agent 可访问的数据表、绑定指标、推荐问题和洞察能力。

### 2.3.1 查看 Agent 列表

#### 操作流程

`Agent 管理 → Agent 列表 → 搜索/筛选/启用停用`

#### 操作步骤

1. 进入【Agent 管理】模块。
2. 在列表中查看 Agent 名称、描述、绑定表、指标、词库、创建人、更新时间和状态。
3. 可按 Agent 名称搜索，或按启用/停用状态筛选。
4. 对 Agent 执行启用、停用、编辑、洞察配置、词库配置或删除操作。

#### 操作说明

- 停用后的 Agent 不应出现在前台默认可选列表中。
- 若历史对话关联的 Agent 已停用，用户查看时会收到无法访问提示。
- 一期暂不支持复制 Agent。

### 2.3.2 新建 Agent

#### 操作流程

`Agent 管理 → 新建 Agent → 基础信息 → 范围选择 → 推荐问题 → 保存`

#### 操作步骤

**第一步：基础信息**

1. 点击【新建 Agent】。
2. 输入 Agent 名称、简介，并上传或更换头像。
3. Agent 名称不可重复。

**第二步：范围选择**

1. 在数据准备模块已接入的数据表中选择本 Agent 可访问的数据表。
2. 支持按分类搜索；支持选择多张表。
3. 不同 Agent 不能重复选择同一张表。
4. 至少选择 1 张表后才能进入下一步。
5. 查看并选择选定数据表下已绑定的指标；可以只选表、不选指标。

**第三步：推荐问题设置**

1. 手动输入推荐问题，一行一个；或使用 AI 根据已绑定表和指标自动生成。
2. 推荐问题将展示在 Data Agent 前台首页。
3. 推荐问题数量要求：最少 3 条，最多 18 条。
4. 保存成功后返回 Agent 列表，并展示新建记录。

#### 注意事项

- 当前步骤信息未填写完整时，无法进入下一步。
- 新建 Agent 流程中包含【范围选择（选表）】阶段；若使用旧版 Agent，可能无法触发该阶段，需联系管理员升级或重建 Agent。

### 2.3.3 编辑 Agent

进入 Agent 详情后，可在【基础设置】中修改：

- Agent 名称、头像、简介
- 绑定数据表和指标
- 推荐问题

修改后点击【保存配置】生效。推荐问题名称必填。

## 2.4 配置 AI 洞察场景与词库

### 2.4.1 AI 洞察思路

用于维护 Agent 的洞察场景和仪表盘模板，支撑前台「经营洞察场景」能力。

#### 操作流程

`Agent 详情 → AI 洞察思路 → 新建场景 → AI 生成 → 人工确认 → 保存启用`

#### 操作步骤

1. 进入目标 Agent 的【AI 洞察思路】页面。
2. 在左侧查看已创建的洞察场景；若无场景，点击【新建场景】。
3. 在左侧与 AI 交互，描述洞察目标；AI 将结构化输出：
   - 关键指标
   - 核心图表
   - 重点问题
   - 洞察图表
4. 人工确认后，内容自动填入右侧表单；不支持 AI 理解的内容需人工补充。
5. 在右侧编辑并保存场景基本信息、整体情况和趋势、深度洞察等内容。
6. 启用场景后，可在前台仪表盘中展示。

#### 操作说明

- AI 生成的指标必须来自已配置的指标库。
- 数据表范围严格限定在该 Agent 已选定的数据表内。
- 「总结与建议」不在此处手工配置，系统会在运行场景分析时自动生成。

### 2.4.2 行业词库

用于增强 Agent 的自然语言理解和业务术语归一化能力。

#### 操作步骤

1. 进入 Agent 详情中的【行业词库】页面。
2. 新增、编辑、删除或启停词条。
3. 支持导入、导出词库；支持搜索标准词和同义词。
4. 停用词条不参与自然语言解析。

#### 操作说明

- 词库仅对当前 Agent 生效。

# 3 前台使用操作流程

## 3.1 进入 Data Agent 首页

### 操作流程

`登录平台 → Data Agent → 查看当前 Agent 首页`

### 操作步骤

1. 登录平台，进入【Data Agent】模块。
2. 首页展示当前 Agent 卡片、Agent 描述、推荐问题、经营洞察场景和自然语言输入框。
3. 左侧展示历史对话列表；右侧为主要问答和分析区域。
4. 确认当前 Agent 是否为预期业务域；不同 Agent 对应不同的数据表、指标和洞察配置。

---

## 3.2 切换 Agent 与新建对话

### 操作流程

`选择 Agent → 新对话 → 开始提问`

### 操作步骤

1. 在 Agent 切换区域选择目标 Agent。
2. 切换后，页面同步刷新以下内容：
   - 欢迎语中的 Agent 名称
   - Agent 描述
   - 推荐问题
   - 经营洞察场景
3. 点击【新对话】，在当前 Agent 下创建新的会话。
4. 新建对话默认继承当前 Agent 的数据范围和指标配置。

### 操作说明

- 用户只能选择后台已配置且已启用的 Agent。
- 系统支持意图识别自动切换 Agent。例如当前在 B Agent 下，若提问内容与 A Agent 绑定数据更相关，系统可自动切换至 A Agent。
- 停用 Agent 不会出现在普通用户可选列表中。

---

## 3.3 自然语言提问与图表生成

### 编写提问指令

建议按「分析目标 + 时间范围 + 分析维度 + 期望输出」组织问题。

**推荐示例：**

> 查看近 6 个月北京市门店营收趋势，并按门店维度输出柱状图。

### 操作步骤

1. 在输入框中输入分析问题。
2. 可直接点击推荐问题快速发起提问。
3. 若推荐问题超过 6 条，可使用【换一换】查看更多。
4. 发送问题后，系统展示思考过程和分析结果。
5. 根据问题内容，系统可能输出：
   - 表格
   - 指标卡
   - 折线图、柱状图、条形图、散点图、饼图等
6. 若当前 Agent 绑定数据中无法回答，系统不应编造数据，而应给出无法回答或需补充信息的提示。

### 一期支持图表类型

- 表格
- 指标卡
- 折线图
- 簇状柱形图
- 条形图
- 散点图
- 饼图

### 操作说明

- 所有问答都依赖 Agent 已绑定的数据表和指标。
- 若图表生成异常，请记录问题内容、当前 Agent、输出结果和报错信息，便于管理员排查。

## 3.4 经营洞察场景分析

经营洞察场景用于一键生成结构化分析仪表盘，适合周期性经营分析、专题复盘等场景。

### 操作流程

`选择洞察场景 → 发起分析 → 查看仪表盘结果`

### 操作步骤

1. 在首页【经营洞察场景】区域选择目标场景卡片。
2. 点击场景后，系统以对话形式发起分析，并展示思考过程。
3. 系统根据预设模板输出以下内容：

**整体情况分析**

- 关键指标（最多 8 个）
- 核心图表（3–9 个）

**洞察分析**

- 重点问题
- 多图表建模（3–9 个，更细粒度下钻分析）

**总结与建议**

- 系统基于整体情况和洞察分析自动生成

4. 点击场景卡片可预览整体输出结果。

### 场景匹配逻辑

- 系统会根据场景名称和描述进行意图识别。
- 从预设场景中匹配相似度最高的 1 个场景。
- 匹配成功后，按该场景模板生成 `.dsh` 格式洞察结果。

---

## 3.5 查看历史对话

### 操作步骤

1. 在左侧历史对话列表中查看过往会话。
2. 点击某条历史对话，可继续查看问答内容和图表结果。
3. 使用搜索框按关键词检索历史对话，快速定位过往问题或分析结果。

### 操作说明

- 历史对话按 Agent 和会话维度组织。
- 若关联 Agent 已停用，历史对话可能无法继续查看。
- 正常情况下，历史对话应展示具体消息时间；若全部显示为「刚刚」，属于显示异常，需联系管理员处理。

# 4 角色操作流程

## 4.1 业务分析师/普通用户

### 日常使用路径

1. 登录平台，进入 Data Agent。
2. 选择与自己业务相关的 Agent。
3. 通过以下任一方式发起分析：
   - 点击推荐问题
   - 输入自然语言问题
   - 选择经营洞察场景
4. 查看指标卡、图表和总结建议。
5. 需要继续分析时，可在同一会话中追问，或新建对话重新开始。

### 提问建议

| 要素 | 建议 |
|------|------|

| 分析维度 | 说明按地区、门店、品类等维度分析 |
| 输出形式 | 如需图表，可直接说明图表类型 |

## 4.2 数据管理员/系统管理员

### 首次上线配置路径

1. 在【数据准备】中接入数据表并完成元数据、维度、指标配置。
2. 在【指标库】中创建并发布业务指标。
3. 在【Agent 管理】中新建 Agent，并完成选表、绑指标、推荐问题配置。
4. 视业务需要配置 AI 洞察场景和行业词库。
5. 启用 Agent 后，通知业务用户开始使用。

### 日常维护

1. 定期检查数据表、字段元数据和指标口径是否准确。
2. 根据业务变化更新 Agent 绑定表、指标和推荐问题。
3. 维护洞察场景模板，确保前台分析结果符合业务预期。
4. 处理用户反馈的问答失败、图表异常、Agent 切换等问题。

# 5 常见问题与注意事项

| 问题 | 可能原因 | 处理建议 |
|------|----------|----------|
| 无法回答或结果为空 | Agent 未绑定相关表/指标 | 检查 Agent 范围选择和指标发布状态 |
| 图表生成错误 | 指标口径异常、维度不匹配或图表配置失败 | 检查指标库配置，记录问题并联系管理员 |
| 推荐问题不显示 | Agent 未配置推荐问题或未启用 | 在 Agent 管理中补充推荐问题 |
| 无法切换目标 Agent | 目标 Agent 已停用或未配置 | 联系管理员启用并检查 Agent 配置 |
| 历史对话全部显示「刚刚」 | 前端时间展示异常 | 记录会话 ID，联系研发排查 |
| 旧 Agent 无法触发选表阶段 | 旧版 Agent 流程不完整 | 建议新建 Agent 或联系管理员升级 |
| 指标口径不一致 | 使用了未发布或未绑定指标 | 优先绑定指标库中已发布指标 |
| 洞察场景匹配不准 | 场景名称/描述与用户问题差异较大 | 优化场景配置或补充行业词库 |

## 安全与合规提示

1. 仅使用本人已获授权的数据表和 Agent，不得通过提问绕过权限控制。
2. 在问题描述中避免输入密码、密钥、身份证号、手机号等敏感明文信息。
3. Data Agent 输出结果基于已配置数据和指标，业务人员应结合实际情况复核结论。
4. 对外分享分析结果前，应确认数据脱敏和访问范围符合合规要求。
