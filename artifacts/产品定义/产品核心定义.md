# 智能建模 — 产品核心定义

> 版本：1.0.0 | 状态：active | 所有者：product-team  
> 本文件是所有 Loop 循环的**唯一产品锚点**，循环定义与评测量规必须引用本文。

---

## 1. 一句话定位

**智能建模**是海致自主建模平台中的 AI 能力：用户用自然语言描述业务需求，系统通过多 Agent 编排，自动完成选表、建模规划、算子参数生成，最终在可视化画布上产出**可运行、可验证、可迭代**的数据模型。

> 核心承诺：**所想即所建** — 思维直达模型，而非思维直达文档。

---

## 2. 什么叫「建模成功」

一次建模交互视为成功，当且仅当满足：

| # | 验收条件 | 对应能力环 |
|---|----------|-----------|
| 1 | 系统正确理解用户意图（建模 / 改写 / 续写 / 问答） | C1 意图理解 |
| 2 | 选对或尊重用户指定的数据表（含多表联合） | C2 选表规划 |
| 3 | 输出完整建模规划 JSON（tables/joins/filters/status） | C2 选表规划 |
| 4 | 生成符合算子 Schema 的参数，画布节点可创建 | C3 算子落地 |
| 5 | 用户可批准/拒绝/修改，流程不中断 | C4 体验可信 |
| 6 | （可选）模型可保存、运行、发布 | C3 算子落地 |

**以下不算成功：**
- 只推荐了表但没有建模规划
- 规划 JSON 为空或 status=failed 且无明确 missing_info
- 算子参数多次重试仍不合规
- 手动选表后被自动推荐覆盖

## 3. 四条能力环（Capability Loops）

```
┌──────────────────────────────────────────────────────────┐
│  C1 意图理解环                                            │
│  用户输入 → RecognitionAgent → 路由到正确子 Agent          │
├──────────────────────────────────────────────────────────┤
│  C2 选表规划环                                            │
│  NL2ModelDesignAgent + NL2TableOperatorAgent              │
│  输出：plan JSON + selected_tables JSON                   │
├──────────────────────────────────────────────────────────┤
│  C3 算子落地环                                            │
│  NL2OperatorAgent → 合规 params → 画布节点 → 可运行       │
├──────────────────────────────────────────────────────────┤
│  C4 体验可信环                                            │
│  流式输出、会话持久、批准/拒绝、上下文引用、可追溯          │
└──────────────────────────────────────────────────────────┘
```

PM Loop 工程**只围绕 C1–C4 能不能变好**，不围绕文档格式好不好。

---

## 4. 主链路（技术实现）

```
用户自然语言
    ↓
RecognitionAgent（意图识别）
    ↓
NL2ModelDesignAgent（建模规划）── JSON: plan
    ↓
NL2TableOperatorAgent（选表）────── JSON: selected_tables
    ↓
NL2OperatorAgent（算子参数）────── JSON: operator_params
    ↓
可视化画布（节点创建 / 连线 / 运行）
```

Agent 间通过 **JSON Schema 契约** 传参，详见 `artifacts/Agent契约/`。

## 5. 产品边界

| 产品 | 核心对象 | 输出 | 与本产品关系 |
|------|----------|------|-------------|
| **智能建模助手** | 数据表、算子、画布 | 可运行模型 | **本产品** |
| Data Agent | 指标、洞察场景 | 图表/仪表盘 | 共享 LLM 平台，不同 Agent 编排 |
| DMC 自主建模 | 算子、画布 | 手动拖拽模型 | 智能建模是其 AI 增强层 |
| ER 数据模型设计 | 实体、字段、关系 | 数据库 Schema | **不是本产品**（见 loops/legacy/） |

## 7. Loop 工程在本产品中的职责

依据 [loop-engineering-core](https://github.com/wiy-whl/loop-engineering-core)：

| 层级 | 本产品中的 Loop | 示例 |
|------|----------------|------|
| L1 全循环 | 主链路 E2E 评测、OPT 回归 | `loops/主链路E2E评测循环.yaml` |
| L2 半循环 | Scenario 入库、Agent 契约变更评审 | PM 确认 expected 后入库 |
| L3 产物辅助 | 白皮书、操作手册维护 | `inputs/docs/` 参考，非主循环 |
| L4 纯人工 | 产品战略、跨产品线定位 | 不做 Loop |
