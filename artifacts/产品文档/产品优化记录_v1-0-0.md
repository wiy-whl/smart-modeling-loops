## 2. 产品优化项明细

### OPT-001 手动选表后仍触发表推荐，且意图分组限制多表选型

| 字段 | 内容 |
|------|------|
| 优先级 | P0 |
| 模块 | 表推荐 / 意图分组选表 |
| 来源 | 2026/07/20 #1 |
| 问题描述 | 用户已手动指定所需数据表后，系统仍继续推荐表；实际业务需同时使用多张表，但当前按「意图分组」每组只能选一张，导致无法一次选齐所需表。 |
| 影响 | 多表联合建模被阻断，与真实业务用法不符。 |
| 优化建议 | 1）已手动指定表时，跳过或弱化自动推荐；2）意图分组支持同组多选；3）明确「手动选表」与「AI 推荐」的优先级与互斥规则。 |
| 验收标准 | 手动指定表后不再强制推荐；同组可多选；所选表完整进入后续建模规划。 |
| 状态 | 待处理 |

---

### OPT-002 手动选表后无建模规划，刷新无效

| 字段 | 内容 |
|------|------|
| 优先级 | P0 |
| 模块 | 建模规划 |
| 来源 | 2026/07/20 #2 |
| 问题描述 | 在手动选表场景下，系统提示「无建模规划」，页面刷新后问题依旧，流程无法继续。 |
| 影响 | 建模主链路中断。 |
| 优化建议 | 排查手动选表结果未正确传入规划服务的问题；失败时给出可操作的错误原因与重试入口，而非仅提示无规划。 |
| 验收标准 | 手动选表成功后可正常生成建模规划；异常时错误信息明确可恢复。 |
| 状态 | 待处理 |

---

### OPT-003 规划建模阶段多次重试仍无法生成符合算子结构的参数

| 字段 | 内容 |
|------|------|
| 优先级 | P0 |
| 模块 | 规划建模 / 算子参数生成 |
| 来源 | 2026/07/23 #1 |
| 问题描述 | 进入规划建模阶段后，多次重试仍未能生成符合算子结构要求的参数。 |
| 影响 | 无法落成可执行模型，核心能力不可用。 |
| 优化建议 | 加强算子 schema 约束与参数校验；失败时返回具体字段级错误；增加结构化重试策略，避免无效重复生成。 |
| 验收标准 | 正常场景下可稳定生成合规算子参数；失败有明确字段级提示。 |
| 状态 | 待处理 |

### OPT-004 推荐表不准确，清空上下文后推荐与问题无关

| 字段 | 内容 |
|------|------|
| 优先级 | P1 |
| 模块 | 表推荐 |
| 来源 | 2026/07/23 #2 |
| 问题描述 | 同一次对话中，首次推荐表与业务问题相关；清空上下文后再次提问，推荐表与问题无关；连续追问 2～3 次仍无关。 |
| 影响 | 推荐可信度下降，用户需反复纠正。 |
| 优化建议 | 推荐应以当前用户意图与业务语义为主，不依赖不稳定的上下文残留；增加推荐结果与问题的相关性校验与兜底策略。 |
| 验收标准 | 清空上下文后，基于新问题仍能推荐相关表；无关推荐比例显著下降。 |
| 状态 | 待处理 |

### OPT-005 手动添加数据表报错；@ 引用表解析失败

| 字段 | 内容 |
|------|------|
| 优先级 | P1 |
| 模块 | 手动选表 / 指令解析 |
| 来源 | 2026/07/23 #3 |
| 问题描述 | 1）手动添加数据表后报错「未筛选到业务匹配的表」；2）部分指令下 AI 无法正确解析用户通过 `@` 引用的数据表。 |
| 影响 | 用户主动供表路径失效，指令交互不可用。 |
| 优化建议 | 区分「业务筛选无结果」与「用户已显式指定表」两种逻辑；完善 `@表名` 的实体解析与绑定。 |
| 验收标准 | 手动添加的表可进入后续流程；`@` 引用可被稳定识别并使用。 |
| 状态 | 待处理 |

### OPT-006 多表联合时表类型划分不准，同表被归为一类导致只能二选一

| 字段 | 内容 |
|------|------|
| 优先级 | P1 |
| 模块 | 表类型划分 / 多表联合建模 |
| 来源 | 2026/07/23 #4；与 OPT-001 相关 |
| 问题描述 | 多表联合建模时，所需数据表被归为同一类型，界面只能二选一；测试中出现同一张表（前文手动拖入对话框的表）被重复归类的情况。 |
| 影响 | 无法同时选用联合建模所需的全部表。 |
| 优化建议 | 修正表类型/意图分组算法；对用户已拖入或已选表做去重与锁定；支持同类型/同组多选。 |
| 验收标准 | 联合建模所需表可同时选中；已选手动表不被错误拆分或互斥。 |
| 状态 | 待处理 |

### OPT-007 基于推荐意图手动选择后仍二次推荐意图

| 字段 | 内容 |
|------|------|
| 优先级 | P1 |
| 模块 | 意图推荐 |
| 来源 | 2026/07/20 #4 |
| 问题描述 | 用户已基于推荐意图完成手动选择后，系统仍再次推荐意图，造成流程重复。 |
| 影响 | 交互冗余，打断建模节奏。 |
| 优化建议 | 用户确认意图后锁定当前意图，进入规划阶段，不再重复推荐；仅在用户主动修改意图时重新推荐。 |
| 验收标准 | 意图确认后不再二次推荐；修改意图时可重新触发。 |
| 状态 | 待处理 |

### OPT-008 解析推荐表信息失败（知识命中仍报错）

| 字段 | 内容 |
|------|------|
| 优先级 | P1 |
| 模块 | 推荐表解析 |
| 来源 | 2026/07/20 #5～#6 |
| 问题描述 | 系统报「解析推荐表信息失败」；即使建模知识检索正确，仍出现该错误。 |
| 影响 | 推荐链路中断，正确知识无法转化为可用表信息。 |
| 优化建议 | 排查知识命中结果到推荐表结构的解析/映射逻辑；知识命中与表解析解耦，分别给出失败原因。 |
| 验收标准 | 知识命中正确时，推荐表可正常解析展示；失败时错误原因可定位。 |
| 状态 | 待处理 |

### OPT-009 输入指令写错后不支持编辑修改

| 字段 | 内容 |
|------|------|
| 优先级 | P2 |
| 模块 | 对话输入 |
| 来源 | 2026/07/20 #3（产品优化） |
| 问题描述 | 用户输入指令内容有误时，不支持对已发送内容进行编辑更改。 |
| 影响 | 需重新输入整段指令，效率低。 |
| 优化建议 | 支持对最近一条用户消息编辑并重新提交；或提供「基于本条修改」快捷能力。 |
| 验收标准 | 可编辑已发送指令并重新触发流程，历史与结果一致更新。 |
| 状态 | 待处理 |

### OPT-011 知识库「维度设计」无内容时仍展示

| 字段 | 内容 |
|------|------|
| 优先级 | P2 |
| 模块 | 知识库 / 结果展示 |
| 来源 | 2026/07/20 #8（产品优化） |
| 问题描述 | 「维度设计」并非所有场景必需；当前无维度设计内容时仍展示该模块，造成困惑。 |

### OPT-012 切换页面导致 AI 流式输出中断；输出中无法上滑查看历史

| 字段 | 内容 |
|------|------|
| 优先级 | P1 |
| 模块 | 前端交互 / 流式输出 |
| 来源 | 2026/07/23 #5（前端问题） |
| 问题描述 | 1）切换到其他页面时，AI 回答停住不动；切回原页面后继续吐字；2）AI 输出过程中对话框无法上滑，影响查看历史内容。 |
| 影响 | 多任务切换体验差；长回答过程中无法回顾上文。 |
| 优化建议 | 流式输出与页面可见性解耦（后台继续接收/缓存）；输出过程中允许用户上滑浏览历史，仅在用户位于底部时自动跟随滚动。 |
| 验收标准 | 切页不中断或切回后无异常卡顿感；输出中可上滑查看历史。 |
| 状态 | 待处理 |
