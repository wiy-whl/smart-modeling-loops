# 1 产品概述

智能建模助手是自主建模平台中的 AI 辅助能力，面向业务分析师和模型开发者提供自然语言驱动的模型构建、调整和补全能力。用户可通过对话描述业务目标、数据范围和处理思路，由助手基于可访问的数据表、算子及模型知识生成建模建议，并实时联动可视化画布。

本手册面向已具备自主建模平台访问权限的用户，说明如何通过智能建模助手完成从数据选择、建模规划、方案确认、模型调整到保存发布的操作。

## 1.1 产品架构

智能建模助手由以下三层组成：

| 层级 | 组成 | 作用 |
|---|---|---|
| 交互层 | 智能助手侧边栏、自然语言输入框、上下文引用 | 接收用户的建模目标、补充条件和改写指令 |
| 智能层 | 建模规划 Agent、数据表知识库、算子知识库、模型知识库 | 分析需求，匹配数据和算子，生成模型方案 |
| 执行层 | 可视化建模画布、数据节点、算子节点、任务执行服务 | 呈现、编辑、运行和保存 AI 生成的模型 |

## 1.2 核心价值

1. **降低建模门槛**：用户可直接用业务语言表达需求，不必从零开始查找算子和配置参数。
2. **提高建模效率**：助手可自动规划数据表、算子和处理步骤，减少重复拖拽与配置操作。
3. **保证过程可控**：所有生成结果均呈现在画布与对话面板中；用户可批准、拒绝或继续修改。
4. **沉淀组织经验**：助手可参考已配置的数据表、算子、模型模板与业务知识，优先复用既有最佳实践。

## 1.3 用户角色

| 角色 | 主要权限 | 典型操作 |
|---|---|---|
| 普通用户/业务分析师 | 在已授权的数据和模型范围内创建、编辑、运行模型 | 选择数据表、发起建模对话、确认方案、查看结果 |
| 模型开发者 | 使用模型管理、数据表、算子和任务能力 | 构建复杂模型、改写/续写、调试、保存与发布 |
| 系统管理员 | 管理数据、算子、知识库、模板及用户权限 | 维护可用数据范围、指令模板与模型知识，处理权限问题 |

# 2 通用操作流程

## 2.1 进入智能建模助手

### 操作流程

`模型管理 → 创建模型 → 选择数据模型 → 打开智能助手侧边栏 → 发起建模`

### 操作步骤

1. 登录自主建模平台，进入【模型管理】。
2. 点击【创建模型】，选择【数据模型】进入建模画布。
3. 确认画布左侧显示【数据】和【算子】资源栏。
4. 在画布右侧打开智能助手面板；若面板未展开，点击界面中的助手入口或 AI 图标。
5. 首次进入时，助手会展示推荐场景和输入框。可直接选择推荐场景，也可输入自定义需求。

> 注意：仅在当前账号具有数据模型创建权限时，才可进入创建模型页面。

## 2.2 选择数据范围

为提升建模建议的准确性，可在发起对话前限定本次建模可使用的数据表范围。未限定时，助手将在当前账号有权限的数据表中进行匹配。

### 操作步骤

1. 在助手输入框上方或提示区域点击【请选择】。
2. 在【选择数据表】弹窗的左侧目录中展开数据目录。
3. 勾选参与本次建模的数据表；已选择的数据表会在弹窗右侧显示。
4. 检查所选表是否包含建模所需的关键字段，例如主体标识、时间、地址、状态或金额等。
5. 点击【确定】保存选择；如需放弃本次选择，点击【取消】。

![选择建模数据表](assets/figma/data-analysis-planning.png){width="6.5in" height="3.466666666666667in"}

*图 2-1：选择数据表并限定建模数据范围*

### 操作说明

- 数据范围仅用于辅助本次建模规划，不会修改数据表权限。
- 选择多个数据表时，应确保表之间存在可关联的字段或在指令中明确说明关联方式。
- 若未找到所需数据表，请联系系统管理员确认数据接入状态和账号权限。

## 2.3 发起建模规划

### 编写建模指令

在输入框中使用自然语言描述建模目标。建议按“业务目标 + 数据范围 + 处理规则/方法 + 期望输出”组织指令。

**推荐示例：**

> 基于近 30 天的旅店住宿信息和重点人员信息，筛选疑似重点人员落脚点；按旅店和人员统计入住次数，输出人员基本信息、旅店名称、入住时间和入住次数。

### 操作步骤

1. 确认已选择数据范围；如不限定数据范围，可直接进入下一步。
2. 在助手输入框中输入建模需求。
3. 需要指向画布中特定对象时，可使用以下任一种上下文引用方式：
   - 将数据表或算子节点拖入输入框；
   - 右键单击节点并选择【引用】；
   - 在输入框中输入 `@`，搜索并选择需要引用的元素。
4. 点击发送按钮，等待助手分析需求。
5. 在助手面板查看生成的建模规划，包括数据表、处理步骤、推荐算子和预期结果。

### 指令编写建议

| 要素 | 建议说明 | 示例 |
|---|---|---|
| 分析目标 | 明确要解决的问题 | 识别疑似重点人员落脚点 |
| 数据范围 | 说明使用的表、时间范围或筛选范围 | 使用近 30 天住宿信息与重点人员信息 |
| 处理规则 | 说明关联、筛选、聚合或算法要求 | 按身份证号关联，按旅店统计次数 |
| 输出结果 | 指定需要的字段和呈现形式 | 输出人员、旅店、入住时间及入住次数 |

## 2.4 确认并生成模型

助手生成方案后，会在对话面板展示待执行步骤、拟使用的数据表和推荐算子。用户应先核对方案，再决定是否执行。

### 操作步骤

1. 阅读助手输出的建模方案，重点核对数据表、关联条件、筛选条件、聚合维度和输出字段。
2. 若助手请求选择或确认某张数据表，在面板中完成选择。
3. 确认方案符合预期后，点击【批准】。
4. 系统会在画布中创建数据节点和算子节点，并按照方案连接节点。
5. 检查画布上的节点名称、连线和节点状态；如有需要，继续通过对话或画布操作调整。
6. 如方案不符合需求，点击【拒绝】，并在输入框中补充原因或重新描述需求。

### 校验要点

- 输入数据是否正确，且与业务需求一致；
- 表之间的关联字段、关联方式是否合理；
- 时间、地域、人员类别等筛选条件是否完整；
- 聚合的分组字段、统计字段和统计方式是否正确；
- 输出字段是否满足后续分析、任务运行或服务发布需要。

## 2.5 改写与续写模型

### 2.5.1 模型改写

模型改写用于调整已生成模型的节点参数、处理逻辑或局部结构。

#### 操作步骤

1. 在画布中选中需要调整的节点；也可在输入框中通过 `@` 引用该节点。
2. 在助手输入框中输入改写要求，例如：
   - “将住宿信息的时间范围修改为近 90 天”；
   - “将聚合方式由计数改为去重计数”；
   - “将分类算法替换为 XGBoost，并保留当前特征字段”。
3. 查看助手提出的变更内容及涉及的节点。
4. 点击【批准】应用变更，或点击【拒绝】保留原模型。
5. 在画布中确认修改后的节点配置和连线。

![模型改写确认](assets/figma/model-rewrite-confirm.png){width="6.5in" height="3.466666666666667in"}

*图 2-3：模型改写建议、批准/拒绝与画布实时联动*

### 2.5.2 模型续写

模型续写用于在已有模型的指定节点之后补充后续处理流程。

#### 操作步骤

1. 在画布中选中作为续写起点的算子节点。
2. 通过右键菜单选择【引用】，或在对话中说明续写起点。
3. 输入后续处理要求，例如：“在此节点后增加模型评估，输出准确率、召回率和 AUC。”
4. 查看助手建议新增的节点、连接关系和参数。
5. 批准方案后，系统会将新增节点连接到指定起点后。
6. 验证新增节点的输入输出字段，必要时继续改写。

> 注意：续写前应确认起点节点已配置完成并具有可用输出；否则助手可能无法生成有效的下游处理方案。

## 2.6 快捷 AI 操作

在画布中选中算子节点后，可通过节点操作菜单直接调用快捷 AI 能力。

| 操作 | 使用方式 | 结果 |
|---|---|---|
| 智能改写 | 选中节点后选择【智能改写】 | 基于自然语言修改当前节点配置或结构 |
| 智能重命名 | 选中节点后选择【智能重命名】 | 根据节点功能和配置生成语义化名称 |
| 智能注释 | 选中节点后选择【智能注释】 | 自动生成节点用途、输入输出与处理逻辑说明 |

### 操作步骤

1. 在画布中单击选中目标算子。
2. 在节点的快捷菜单中选择【智能改写】、【智能重命名】或【智能注释】。
3. 若为智能改写，在弹出的对话区域补充具体要求并发送。
4. 查看生成结果；名称、注释或配置变更符合预期后保存模型。

## 2.7 保存、运行与发布模型

### 保存模型

1. 在画布上完成模型检查后，点击页面右上角【保存】。
2. 首次保存时，按界面提示填写模型名称及必要描述。
3. 保存成功后，可继续编辑；后续修改应再次点击【保存】。

### 运行与查看结果

1. 确认所有节点已完成配置，且没有必填参数缺失提示。
2. 根据平台界面提供的运行入口发起模型运行。
3. 在模型结果或任务管理页面查看任务状态、运行日志和输出结果。
4. 如运行失败，根据报错定位数据权限、字段、参数或节点连接问题，并使用模型改写功能调整。

### 发布模型

模型发布功能受角色权限和平台配置控制。具备发布权限时：

1. 确认模型运行结果符合预期。
2. 点击【保存并发布版本】或平台提供的发布入口。
3. 填写版本说明，确认发布范围和调用权限。
4. 提交发布后，在模型管理中确认版本状态。

> 注意：发布前请完成数据口径、字段脱敏、权限范围和结果准确性检查。

# 3 角色操作流程

## 3.1 模型开发者

### 用户登录

使用已分配的账号登录平台。首次使用前，确认已获得模型管理、相关数据目录和所需算子权限。

### 查看数据表

1. 进入创建模型页面，在左侧【数据】栏查看可用目录和数据表。
2. 使用搜索或目录展开方式定位数据表。
3. 在选择数据范围窗口中勾选本次建模需要的数据表。
4. 如需理解字段口径，查看表结构说明；字段不清晰时不建议直接发起建模。

### 查看算子

1. 在左侧【算子】栏浏览可用算子。
2. 结合助手建议确认算子功能、输入输出字段和参数要求。
3. 对 AI 已生成的节点，可通过节点配置面板进行人工复核和调整。

### 创建模型

按照“2.1 进入智能建模助手”至“2.6 快捷 AI 操作”的流程完成模型构建和调优。

### 发布模型

按照“2.7 保存、运行与发布模型”的流程保存、验证并发布模型版本。

## 3.2 系统管理员

### 管理数据和权限

1. 确保数据表已接入平台，且目录、表结构和字段说明完整。
2. 按组织和岗位分配数据表、模型和算子的访问权限。
3. 定期检查无权限、字段缺失或表结构变更导致的建模失败问题。

### 维护算子和知识库

1. 维护算子的功能描述、适用场景、参数说明和输入输出约束。
2. 将高质量的历史模型、业务文档和建模规范纳入模型知识库。
3. 更新数据表业务描述，使助手能够正确理解表的用途与字段含义。

### 配置指令模板

1. 基于常见业务场景梳理标准化指令，如风险识别、异常检测、名单比对、统计聚合等。
2. 配置可复用的指令模板，并明确模板中需要用户补充的参数。
3. 定期收集用户反馈，优化模板内容和推荐场景。

### 处理异常

当用户无法选择数据、助手无法生成方案或模型运行失败时，按以下顺序排查：

1. 用户是否具有目标数据表、算子和模型的权限；
2. 数据表是否可用，字段是否与业务描述一致；
3. 引用的画布节点是否已正确配置并有输出；
4. 指令是否包含明确的业务目标、数据范围和输出要求；
5. 模型运行日志是否存在字段、类型、连接或参数错误。

# 4 常见问题与注意事项

| 问题 | 可能原因 | 处理建议 |
|---|---|---|
| 找不到数据表 | 账号无权限、数据未接入或目录未展开 | 联系管理员确认数据接入及授权状态 |
| 助手推荐的数据不符合预期 | 指令描述不完整或未限定数据范围 | 选择数据范围，并补充业务口径、时间范围、关联字段 |
| 生成方案无法批准 | 待确认的数据表或节点未完成选择 | 根据提示补充选择项，重新核对方案 |
| 改写后结果不符合预期 | 改写对象或条件描述不明确 | 引用具体节点，并明确“修改什么、修改为多少、保留什么” |
| 续写失败或无法连接 | 起点节点无有效输出，或下游字段不匹配 | 先检查起点节点输出字段和运行状态，再重新发起续写 |
| 模型运行失败 | 字段、参数、权限或节点连接存在问题 | 查看任务日志，修改对应节点后重新运行 |

## 安全与合规提示

1. 仅使用本人已获授权的数据表和模型，不得通过指令绕过权限控制。
2. 在指令、注释和模型名称中避免输入密码、密钥、身份证号、手机号等敏感明文信息。
3. 发布模型前应确认输出数据的脱敏策略、访问范围和业务合规性。
4. AI 生成的模型方案仅作为辅助建议，必须由业务人员或模型开发者完成复核、验证和最终确认。
